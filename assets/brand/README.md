# GeoGi Brand Assets

The only production authority for the GeoGi logo is `logo-system/v1.0/`.
Its frozen manifest is `logo-system/v1.0/manifest.json` (GeoGi Logo System v1.0.0, frozen 2026-08-13).

Production usage must follow the canonical package README and the repository brand contract in `docs/brand/GeoGi_Logo_System_v1.0.md`.

## Deprecated legacy assets

The following retained files are deprecated and must not be referenced by new or existing production code:

- `geogi_logo_dark_*`
- `geogi_logo_mark_dark_*`
- `geogi_logo_core_*`
- `geogi_mark_transparent_*`

They remain temporarily to avoid breaking unknown historical consumers. Do not copy, modify, regenerate, or restore them to production use.
