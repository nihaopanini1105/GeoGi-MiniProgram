# GeoGi Logo System v1.0

- Version: 1.0.0
- Frozen: 2026-08-13
- Authority: `assets/brand/logo-system/v1.0/manifest.json`

## Production usage contract

| Context | Canonical asset |
|---|---|
| Light background | Horizontal navy |
| Dark background | Horizontal white |
| Narrow space | Vertical navy or white, selected for the background |
| Very small UI | Mark |
| App / Mini Program icon | App icon |

Always preserve the source aspect ratio (`aspectFit` in the Mini Program). The GeoGi wordmark weight is Regular / 400.

## Prohibited changes

- Do not generate, redraw, approximate, reshape, rotate, stretch, or recolor the GeoGi logo.
- Do not change the Orbit ring, upper-right dot, blue-shape proportions, or wordmark weight.
- Do not add a white backing card or another artificial background behind a transparent logo.
- Do not use AI-generated or screenshot-derived substitutes.
- Do not use the deprecated `geogi_logo_dark_*`, `geogi_logo_mark_dark_*`, `geogi_logo_core_*`, or `geogi_mark_transparent_*` assets in production.

Any replacement requires a new, explicitly frozen logo-system version and manifest.
