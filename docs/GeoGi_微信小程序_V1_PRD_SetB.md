# GeoGi 微信小程序 V1 PRD（Set B 深色版）

版本：v1.0

适用范围：GeoGi 中国市场品牌 GEO 服务第一阶段客户门户。

## 1. 产品定位

GeoGi 小程序第一阶段不是完整 GEO SaaS，也不是大量教育内容的知识产品，而是轻量客户门户，承担 5 类核心职责：

1. 品牌与服务介绍；
2. 品牌初步诊断申请；
3. GeoGi 研究中心内容展示；
4. 我的诊断报告查看；
5. 在必要节点联系 GeoGi 官方顾问。

联系官方不作为一级导航。

## 2. 核心业务闭环

客户进入小程序 → 了解 GeoGi → 提交品牌诊断信息 → 后端创建诊断申请 → 飞书通知员工 → 员工运行 GeoGi OS 完成初步诊断 → 人工审核报告 → 发布报告到小程序 → 客户查看报告 → 必要时预约报告解读并转化为后续 GEO 服务。

## 3. 一级导航

底部固定 4 个 Tab：

- 首页
- 诊断
- 研究
- 报告

不设置：联系、服务、我的。

## 4. 视觉基线

采用用户确认的 Set B 深色 AI 视觉：

- 深海军蓝 / 黑蓝背景；
- GeoGi 蓝色渐变作为高亮；
- 卡片为半透明深蓝层级；
- 弱边框、低饱和阴影、少量霓虹光效；
- 空间感优先，不堆叠大量内容；
- 页面左右安全边距建议 32–40rpx；
- 卡片内边距建议 28–36rpx；
- 主要区块垂直间距建议 32–48rpx；
- 主要按钮高度建议 88–96rpx；
- 标题、正文、辅助文字建立清晰层级。

Logo 必须使用仓库中的 GeoGi 正式资产，不允许 AI 重绘或近似替代。

首页 Slogan 固定为：

> 让品牌在 AI 时代被看见、被理解、被选择

## 5. 首页

### 5.1 目标

10 秒内让客户理解 GeoGi 并进入诊断或报告。

### 5.2 模块

1. 顶部品牌标识；
2. Hero Banner：固定 Slogan、简短说明、主 CTA“开始品牌初步诊断”、次 CTA“查看我的诊断报告”；
3. GeoGi 核心能力：GEO 诊断、GEO 优化方案、GEO 优化执行；
4. 覆盖平台：豆包、腾讯元宝、通义千问、DeepSeek、Kimi；
5. 最新研究：只展示 2–3 条官网研究中心最新内容；
6. 必要时的顾问联系入口。

首页不做长篇 GEO 科普，不重复官网研究中心内容。

## 6. 品牌初步诊断

### 6.1 目标

2–3 分钟内完成信息提交。

### 6.2 三步表单

#### Step 1：品牌基础信息

必填：
- 品牌名称
- 所属行业
- 细分领域

选填：
- 官网
- 公众号 / 小程序 / 官方店铺 / 其他官方渠道

注意：官网作为选填项，UI 不显示红色必填标记。

#### Step 2：业务与客户信息

- 核心产品或服务
- 主要客户是谁
- 客户通常解决什么问题
- 主要经营区域 / 市场
- 核心优势或希望重点检测的问题
- 主要竞品，最多 3 个
- 诊断目标，最多选择 3 项
- 附件上传

#### Step 3：联系方式

- 联系人
- 授权手机号
- 公司名称（选填）
- 补充说明（选填）
- 隐私授权

### 6.3 提交结果

提交成功后必须：

- 生成唯一诊断申请编号；
- 创建客户 / 项目记录；
- 写入内部飞书工作台；
- 通知指定员工；
- 小程序本地和服务端均保留项目归属；
- 客户在“报告”Tab 中能看到状态。

## 7. 研究中心

### 7.1 原则

官网研究中心为唯一内容源，小程序不重复维护第二套文章库。

### 7.2 展示

- 文章列表
- 搜索
- 分类筛选
- 文章详情或官网原文

分类以 GeoGi 官网 / 微信公众号既有内容合集为准，具体分类由内容配置动态读取，不在前端写死不可变业务规则。

## 8. 报告中心

### 8.1 无报告

展示空状态并引导“开始品牌诊断”。

### 8.2 有报告

列表卡片展示：

- 品牌名称
- 项目编号
- 提交时间
- 当前状态
- 报告完成时间（如已完成）

客户可见状态统一为：

1. 已提交
2. 资料待补充
3. 诊断处理中
4. 报告审核中
5. 报告已完成

### 8.3 报告详情

V1 不做复杂在线 Dashboard，优先：

- 简短诊断摘要
- 报告状态
- PDF 在线查看 / 打开
- 报告完成后的“预约报告解读”入口

未经人工审核的报告不得发布给客户。

## 9. 联系官方

联系页保留为二级页面，不进入底部导航。

必要入口位置：

- 首页底部：咨询 GeoGi 顾问；
- 诊断表单：不知道怎么填时联系顾问；
- 提交成功页：补充说明时联系顾问；
- 报告完成页：预约报告解读。

正式信息：

- 联系邮箱：geogi@geogi.cn
- 官网：www.geogi.cn
- 企业微信 / 顾问二维码：使用用户确认的正式二维码资产
- 微信公众号二维码：使用用户确认的正式二维码资产

## 10. 飞书协作闭环

客户提交后：

1. 小程序后端校验；
2. 创建诊断申请；
3. 写入飞书多维表格 / 内部诊断工作台；
4. 飞书机器人或应用通知负责人；
5. 员工领取处理；
6. 员工运行 GeoGi OS；
7. 报告完成人工 QA；
8. 报告 PDF 绑定客户项目；
9. 小程序报告状态更新为“报告已完成”。

飞书是内部通知与协作层，不是客户报告唯一数据源。

## 11. V1 明确不做

- 客户自助运行完整 GeoGi OS；
- 全自动登录所有中国 AI 平台；
- 复杂企业多租户；
- 在线支付与发票；
- 复杂 Action Center；
- 自动发布内容；
- 自动发布未经人工审核的报告；
- 长篇 GEO 教育课程；
- 对 AI 排名、引用或推荐结果做保证。

## 12. V1 验收标准

1. 四个底部导航正确：主页、诊断、研究、报告；
2. 联系官方不在一级导航；
3. 首页采用 Set B 深色视觉并拉大空间；
4. 首页 Slogan 为“让品牌在 AI 时代被看见、被理解、被选择”；
5. 正式 GeoGi Logo 资产正确显示；
6. 官网字段为选填，无红色必填标记；
7. 客户可完成三步诊断提交；
8. 正常服务配置下，提交后生成项目编号并触发飞书通知；
9. 报告页能显示项目状态；
10. 员工发布 PDF 后客户能打开报告；
11. 研究中心内容以官网为唯一来源；
12. 联系邮箱统一为 geogi@geogi.cn；
13. 所有关键提交、状态和报告操作具备日志；
14. 微信开发者工具中主要页面无明显溢出、遮挡、过密或小屏错位。
